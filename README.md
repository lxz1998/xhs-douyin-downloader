# 去水印下载器（抖音 / 小红书）

粘链接 → 拿无水印视频 / 原图 → 单张下载或打包。

整个工具跑在你自己的电脑上：起一个本地 Flask，浏览器打开 `127.0.0.1:8090`，解析和代理下载都在本机完成，不经过任何第三方服务器，不需要域名、备案、账号。

## 快速开始

**Windows**：双击 `启动.bat`。第一次运行会自动装依赖，装完浏览器自动打开。
关掉那个黑窗口就是停止服务。

**macOS / Linux**：

```bash
pip install -r requirements.txt
python app.py            # 默认 8080 端口，用 PORT=8090 可改
# 浏览器打开 http://127.0.0.1:8080
```

**想让同一局域网的同事也用**：启动后控制台会打印 `Running on http://192.168.x.x:8090`，
把这个地址发给他，他用浏览器直接打开就行，不用装任何东西。前提是你这台机器开着。

## 需要什么

| 依赖 | 说明 |
|---|---|
| Python 3.10+ | 跑后端 |
| Chrome（**仅抖音需要**） | 抖音的详情接口要完整浏览器指纹 + 动态签名，纯 HTTP 走不通。程序会自己找 `Google Chrome`、`Chromium`、`Edge` 的常见安装路径；找不到就自动降级，**小红书完全不受影响** |

## 支持什么

| 平台 | 视频 | 图集 | 说明 |
|---|---|---|---|
| 抖音 | ✓ 无水印 | ✓ | 分享文案整段粘进来即可 |
| 小红书 | ✓ 最高画质 | ✓ 最高清原图 | 匿名拿不到作者互动数（会留空） |

**不支持**：微信视频号（加密且无公开分享页）、快手 / B 站 / 微博（没做）、私密或已删除作品、需要登录才能看的内容。

## 一次多条 + 历史

- **一次最多 8 条**：多段分享文案一起粘进来，自动抠出所有链接、去重，逐条解析。
  串行是有意的——并行容易被风控，而且串行能边解析边出结果。
- **历史**：解析成功后自动记一条（时间 / 平台 / 标题 / 张数），存在 `~/.watermark/history.json`。
  点一条重新解析，`×` 删单条，右上「清空」全删。只存元信息，不存直链（直链会过期）。

## 已知限制（这些不是 bug）

1. **小红书链接必须带 `xsec_token`**。把 `?...&xsec_token=...` 整段保留；截掉 token 后平台返回登录墙，
   会提示「可能是私密/已删除」。从 App 或网页复制出来的链接本来就是完整的。
2. **图片上的水印去不掉**。小红书把自己的水印烙进了图片本身，直链拿到的最高清版也带着它。
   真正意义上的「去水印」只对**视频**成立（拿的是无水印源）；图集这条做的是「拿原图」。
3. **抖音在机房 / 云服务器 IP 上一定失败**。风控，不是代码问题。要抖音就只能跑在自己家的宽带上。
4. **视频直链带签名，会过期**。拿到就下，别存着以后用。
5. **小红书视频是原始档，可能很大**。实测一条 62 秒的 4K 竖屏视频有 186MB。

## 出问题时

```bash
python selftest.py                              # 不联网，只测路由与本地逻辑
python selftest.py "<一条真实的小红书链接>"      # 加上真实解析 + 下载 + 视频 Range
```

退出码 0 = 全过。看 `[FAIL]` 那行给的线索，比盯着页面猜快。
